### Code themes

The `/code` entry's themes other than `light` and `dark` are ported from these highlight.js 11.12.0 style sheets
(their colors and font styles, written as inline CSS), distributed with highlight.js under the license above. Each
names its own authors:

- `github-light`: `styles/github.css` (Theme: GitHub, by github.com)
- `github-dark`: `styles/github-dark.css` (Theme: GitHub Dark, by github.com)
- `one-dark`: `styles/atom-one-dark.css` (from the One Dark Syntax theme, https://github.com/atom/one-dark-syntax)
- `monokai`: `styles/monokai.css` (Monokai style, ported by Luigi Maselli, http://grigio.org)
- `dracula`: `styles/base16/dracula.css` (Mike Barkmin, based on the Dracula Theme, http://github.com/dracula; MIT or more permissive, via base16-schemes-source)
- `nord`: `styles/nord.css` (Nord highlight.js, https://github.com/arcticicestudio/nord-highlightjs; MIT, copyright (c) 2017-present Arctic Ice Studio and Sven Greb)
- `solarized-light`, `solarized-dark`: `styles/base16/solarized-light.css`, `styles/base16/solarized-dark.css` (Ethan Schoonover, modified by aramisgithub; MIT or more permissive, via base16-schemes-source)
